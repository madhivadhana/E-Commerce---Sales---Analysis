# E-Commerce Sales Analysis Using SQL

## Project Overview
This project analyzes e-commerce sales data using MySQL to understand customer purchasing behavior, product performance, revenue generation, and order delivery performance.

## Objectives
- Analyze revenue generated from delivered orders.
- Identify top-selling products and product categories.
- Evaluate customer purchasing behavior.
- Compare sales performance across delivery cities.
- Analyze order status and delivery performance.

## Database Tables
- Customers
- Orders
- Order Items
- Products
- Categories
- Deliveries

## SQL Skills Demonstrated
- Filtering using WHERE, IN, BETWEEN, and LIKE
- Aggregate functions: SUM, AVG, COUNT, MIN, MAX
- GROUP BY and HAVING
- Sorting and limiting results
- INNER JOIN and LEFT JOIN
- Common Table Expressions (CTEs)
- Subqueries
- CASE statements
- String functions and date functions

## Tools Used
- MySQL

## Key Deliverables
- SQL queries for business analysis
- Revenue and product performance analysis
- Customer and delivery performance analysis

## Conclusion
This project demonstrates practical SQL skills for analyzing e-commerce data and converting business questions into meaningful insights to support data-driven decisions.
